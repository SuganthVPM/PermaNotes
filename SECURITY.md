# Security policy

## Supported versions

Security fixes are targeted at the latest stable version of PermaNotes. If you
can safely reproduce the issue, check for an update through the Microsoft Store
or [GitHub Releases](https://github.com/SuganthVPM/PermaNotes/releases), depending
on where you installed the app. Reports about development builds are welcome.
Include the branch and commit SHA if you know them.

## Reporting a vulnerability

Open the [PermaNotes Security tab](https://github.com/SuganthVPM/PermaNotes/security)
on GitHub and select **Report a vulnerability** if the button is available. This
opens a private report for the maintainers.

If the button is unavailable, open a [GitHub issue](https://github.com/SuganthVPM/PermaNotes/issues/new)
titled **Private security contact request** and ask for a private way to share
the report. Keep vulnerability details, reproduction steps, and attachments
out of the public issue.

In your private report, include what you know about the following:

- The PermaNotes version, Windows version, and installation source (Microsoft
  Store, GitHub installer, portable build, or source build).
- What happened, how to reproduce it, and how it could affect users or their data.
- A minimal sample note, image, or clipboard input, if it helps reproduce the
  issue. Use test data and remove personal information, secrets, and private note
  content from any files, screenshots, or logs you share.

## Coordinated disclosure

Please keep the details private while the report is investigated. The maintainer
may ask for more information to reproduce the issue and coordinate disclosure
with you once a fix or mitigation is available.
